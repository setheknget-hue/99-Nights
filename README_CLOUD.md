# ដំឡើង Cloud (ធ្វើតែម្តង · ឥតគិតថ្លៃ · ~៥ នាទី)

Cloud ធ្វើឲ្យ ២ យ៉ាងដំណើរការ៖
1. **គណនី**៖ បង្កើតម្តង ហើយវាយ «ឈ្មោះ + លេខសម្ងាត់» ចូលពីទូរស័ព្ទណាក៏បាន (មិនបាច់ភ្ជាប់ Google/Facebook)។
2. **លេងអនឡាញជាមួយមិត្ត**៖ Add មិត្ត អញ្ជើញ ចូលបន្ទប់ — ដំណើរការលើ Wi-Fi និងទិន្នន័យទូរស័ព្ទ គ្មានបញ្ហាភ្ជាប់គ្នាមិនបាន។

## ជំហាន
1. ចូល https://console.firebase.google.com (ប្រើ Gmail) → **Add project** → ដាក់ឈ្មោះ (ឧ. forest-nights) → បិទ Google Analytics → Create។
2. ម៉ឺនុយឆ្វេង **Build → Realtime Database → Create Database** → ជ្រើសតំបន់ **Singapore** → ជ្រើស **Start in locked mode** → Enable។
3. ចុចផ្ទាំង **Rules** → លុបអ្វីដែលមាន ហើយបិទភ្ជាប់កូដខាងក្រោម → ចុច **Publish**៖

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "names": { "$k": { ".read": true, ".write": "!data.exists()" } },
    "data":  { "$k": { "$h": { ".read": true, ".write": true } } },
    "board": { ".read": true, "$k": { ".write": true } },
    "net":   { "$id": { ".read": true, ".write": true } }
  }
}
```

4. ផ្ទាំង **Data** → ចម្លង URL ខាងលើ (ឧ. `https://forest-nights-xxxx-default-rtdb.asia-southeast1.firebasedatabase.app`)។
5. បើកឯកសារ **config.js** (ក្នុង zip នេះ) → ដាក់ URL នោះចន្លោះសញ្ញា `''`៖
   `window.FN_CLOUD_URL='https://forest-nights-xxxx-default-rtdb.asia-southeast1.firebasedatabase.app';`
6. Upload ឯកសារទាំងអស់ (`index.html`, `sw.js`, `config.js` ...) ទៅ GitHub ជំនួសឯកសារចាស់។

## ពិនិត្យថាដំណើរការ
- ទំព័រចូលគណនី ត្រូវបង្ហាញអក្សរបៃតង «☁️ បានភ្ជាប់ Cloud»។ បើជាអក្សរក្រហម «⚠ មិនទាន់កំណត់ Cloud» មានន័យថា URL ក្នុង config.js មិនទាន់ត្រូវ។
- បង្កើតគណនីលើទូរស័ព្ទមួយ → លើទូរស័ព្ទមួយទៀត វាយឈ្មោះ + លេខសម្ងាត់ដដែល → ចូលបាន។
- បន្ទប់មិត្តភក្តិ៖ ចំណុចពណ៌បៃតងក្បែរ «មិត្តភក្តិ» មានន័យថាអនឡាញ។

## របៀបដំណើរការ
- `names/<ឈ្មោះ>` សរសេរបានតែម្ដង → ឈ្មោះមិនអាចស្ទួនបាន។
- ទិន្នន័យអ្នកលេងរក្សាក្នុង `data/<ឈ្មោះ>/<hash(ឈ្មោះ+លេខសម្ងាត់)>` → ត្រូវការឈ្មោះ + លេខសម្ងាត់ត្រូវគ្នាទើបចូលបាន។
- `net/...` ជាកន្លែងផ្ញើសារ (សំណើមិត្ត បន្ទប់ ទីតាំងអ្នកលេង) រវាងទូរស័ព្ទ។
- គណនីចាស់ក្នុងឧបករណ៍ នឹងត្រូវផ្ទេរឡើង cloud ដោយស្វ័យប្រវត្តិពេលចូលគណនីលើកដំបូង។
- ចំណាំ: ក្នុងប្រព័ន្ធឥតគិតថ្លៃរបស់ Firebase មានកំណត់ ១០០ ការតភ្ជាប់ក្នុងពេលតែមួយ និង ១០GB/ខែ គ្រប់គ្រាន់សម្រាប់លេងជាមួយមិត្តភក្តិ។

# និយាយគ្នាក្នុងហ្គេម (Voice Chat · លេងជាក្រុម)

ដំណើរការដោយស្វ័យប្រវត្តិពេលលេងជាក្រុមអនឡាញ។ មិនបាច់ដំឡើងអ្វីបន្ថែមទេ។

## របៀបប្រើ
- ពេលចូលហ្គេមជាក្រុម មានប៊ូតុង ២ នៅជ្រុងខាងស្តាំលើ (ក្រោមប៊ូតុងឃ្លាំង)៖
  - **🎤 មីក្រូហ្វូន** ចុចដើម្បី បើក/បិទ សំឡេងនិយាយរបស់អ្នក (ក្រហម = បិទ · បៃតង = បើក · មានរង្វង់ភ្លឺពេលអ្នកកំពុងនិយាយ)។ លើកុំព្យូទ័រចុចគ្រាប់ចុច **V** បាន។
  - **🔈 ស្តាប់** ចុចដើម្បី បើក/បិទ ការស្តាប់មិត្ត។
- ចុចបើកមីក្រូហ្វូនលើកដំបូង ទូរស័ព្ទ/កម្មវិធីរុករកនឹងសួរសិទ្ធិ → ចុច «អនុញ្ញាត»។
- មីក្រូហ្វូនបិទជាធម្មតា រហូតដល់អ្នកបើក។ មិត្តដែលកំពុងនិយាយ មានសញ្ញា 🎙 ក្បែរឈ្មោះក្នុងបញ្ជីក្រុម។
- ប្រើ **កាស (headset)** ដើម្បីកុំឲ្យមានសំឡេងបន្ទរ។

## ភាពច្បាស់ និងល្បឿន
- សំឡេងផ្ទាល់ពីអ្នកទៅអ្នក (WebRTC) មិនឆ្លងម៉ាស៊ីនមេទេ ដូច្នេះយឺតតិច។
- កូឌិក Opus (mono · ~៣២ kbps) មានការកាត់សំឡេងរំខាន សំឡេងបន្ទរ និងកម្រិតសំឡេងស្វ័យប្រវត្តិ ក៏រក្សាសំឡេងឲ្យច្បាស់ពេលអ៊ីនធឺណិតខ្សោយ (FEC)។
- ក្នុង ៤ នាក់ ម្នាក់ៗភ្ជាប់ទៅមិត្ត ៣ នាក់ ប្រើទិន្នន័យតិច (~២០–៤០ kbps ក្នុងមួយអ្នក)។

## បើមិត្តស្តាប់គ្នាមិនឮ (សារ «⚠ ភ្ជាប់សំឡេង … មិនបាន»)
សារនេះមានន័យថា បណ្តាញរបស់ទូរស័ព្ទ (ជាពិសេស 4G/5G) រារាំងការភ្ជាប់ផ្ទាល់ ហើយត្រូវការ **ម៉ាស៊ីនបញ្ជូន (TURN)** ដែលចែកសំឡេងឆ្លងកាត់។ ម៉ាស៊ីន TURN សាធារណៈដែលហ្គេមប្រើជាលំនាំដើម មិនអាចទុកចិត្តបានទេ។ ការដោះស្រាយល្អបំផុតគឺដាក់ TURN របស់អ្នកផ្ទាល់ (ឥតគិតថ្លៃ ២០ GB/ខែ ពិតជាសម្រាប់សំឡេងក្រុមតូចគ្រប់គ្រាន់ — សំឡេង ៣២ kbps ប្រហែល ០.១៤ GB/ម៉ោង/មនុស្ស)៖

1. ចូល **https://dashboard.metered.ca/signup** ចុះឈ្មោះឥតគិតថ្លៃ (ប្រើ Gmail) ហើយជ្រើសផែនការ **Free**។
2. បង្កើត App (ដាក់ឈ្មោះអ្វីក៏បាន ឧ. forest-nights)។
3. ទៅ **TURN Server** → ចុច **Add Credential** (បង្កើត username/password) → ចុច **Instructions** ដើម្បីមើល `iceServers`។
4. បើក `config.js` ក្នុងហ្គេម ដោះសញ្ញា `/*` និង `*/` ជុំវិញផ្នែក `window.FN_ICE` ហើយជំនួស `YOUR_USERNAME` និង `YOUR_PASSWORD` ដោយតម្លៃរបស់អ្នក (បើ Metered ឲ្យ hostname ផ្សេងពី `standard.relay.metered.ca` សូមប្រើតាមនោះ)។
5. Upload `config.js` ទៅ GitHub ហើយផ្ទុកទំព័រឡើងវិញ។ **ទោះអ្នកលេងម្នាក់ៗបើក ក៏ត្រូវប្រើ config នេះដូចគ្នា ព្រោះវាជាឯកសារនៃហ្គេម។**

ចំណាំ៖ ព័ត៌មាន TURN ក្នុង `config.js` អ្នកណាបើកគេហទំព័រក៏អាចមើលឃើញ។ ហានិភ័យគឺមានតែអ្នកផ្សេងប្រើកូតា ២០ GB របស់អ្នកអស់ ប៉ុន្តែអ្នកអាចលុប/បង្កើតព័ត៌មានថ្មីបានគ្រប់ពេលក្នុង dashboard។

សារកំហុសនឹងបង្ហាញលេខ `host / stun / turn` ដើម្បីជួយវិនិច្ឆ័យ៖ បើ `turn:0` មានន័យថា ម៉ាស៊ីន TURN មិនដំណើរការ ឬព័ត៌មានមិនត្រឹមត្រូវ។ បើ `turn` មានលេខ តែនៅតែភ្ជាប់មិនបាន សូមផ្ញើសារនោះមកខ្ញុំ។

## ភាពឯកជន
សំឡេងមិនត្រូវបានថត ឬផ្ញើទៅម៉ាស៊ីនមេទេ។ មានតែសារតភ្ជាប់ (សញ្ញា) ដែលឆ្លងតាមបន្ទប់ហ្គេមដើម្បីរកគ្នាឃើញ។ មីក្រូហ្វូនបិទទាំងស្រុងពេលចេញពីហ្គេម។

## ការដោះស្រាយបញ្ហា
- **ត្រូវដាក់កំណែថ្មីទាំងអស់គ្នា៖** អ្នកលេងគ្រប់គ្នាត្រូវប្រើកំណែតែមួយ (upload `index.html`, `sw.js` ទៅ GitHub ហើយផ្ទុកទំព័រឡើងវិញ ២ ដង)។ បើមានមិត្តម្នាក់ប្រើកំណែចាស់ គាត់នឹងមិនមានប៊ូតុងសំឡេង ហើយសំឡេងមិនភ្ជាប់។
- ពេលភ្ជាប់បាន នឹងមានសារ «🎧 ភ្ជាប់សំឡេងជាមួយ … រួចហើយ» (ប្រហែល ៣–១០ វិនាទីក្រោយចាប់ផ្តើម)។ បើមានសារ «⚠ ភ្ជាប់សំឡេង … មិនបាន» មានន័យថាបណ្តាញរារាំង ត្រូវការ TURN (មើលខាងលើ)។
- ត្រូវចុចបើក 🎤 ទាំងអ្នកនិយាយ ហើយ 🔈 ត្រូវតែបៃតង (បើក) ទាំងអ្នកស្តាប់។

# លេងអនឡាញជាក្រុម (v8)

**ត្រូវដំឡើង Cloud (Firebase) ជាមុន** តាម `README_CLOUD.md` (៥ នាទី ឥតគិតថ្លៃ) ទើបគណនីចងចាំ និងមិត្តរកគ្នាឃើញលើគ្រប់បណ្តាញ។ បើទុក config.js ទទេ ហ្គេមប្រើ WebRTC ដែលអាចភ្ជាប់គ្នាមិនបានលើបណ្តាញទូរស័ព្ទមួយចំនួន។

## របៀបលេង
1. ចូលគណនី → នៅបន្ទប់ (Lobby) ចុចប៊ូតុង **👥 មិត្តភក្តិ** (បន្ទប់មិត្តភក្តិ ដាច់ដោយឡែក)។ ផ្ទាំង **🏠 បន្ទប់រង់ចាំ** សម្រាប់បង្កើត/ចូលបន្ទប់ និងអញ្ជើញមិត្ត។
2. **ID របស់ខ្ញុំ** (៦ តួ) — ឲ្យមិត្តដើម្បី add។
3. **Add មិត្ត**: វាយ ID មិត្ត → ចុច `+ Add` → មិត្តទទួលបានសំណើ ហើយចុច “ទទួល”។
   បើមិត្តមិនទាន់អនឡាញ សំណើនឹងផ្ញើដោយស្វ័យប្រវត្តិពេលគាត់បើកហ្គេម។
4. **បង្កើតបន្ទប់** → ទទួលបានកូដបន្ទប់ ៥ តួ។
   - មិត្តវាយកូដ → ចុច “ចូលរួម” ឬ
   - ចុច “អញ្ជើញ” ក្បែរឈ្មោះមិត្ត → មិត្តឃើញការអញ្ជើញ ហើយចុច “ចូលរួម”។
5. ម្ចាស់បន្ទប់ 👑 ចុច **▶ ជ្រើសរើសវគ្គ** → អ្នកទាំងអស់ចូលលេងជាមួយគ្នា (ច្រើនបំផុត ៤ នាក់)។

## ក្នុងហ្គេមជាក្រុម
- ឃើញមិត្ត ឈ្មោះ និងជីវិតលើក្បាល · បញ្ជីក្រុមនៅប្រអប់ខាងឆ្វេងលើ។
- សត្វ ពេលវេលា ព្យុះ ភ្លើង តង់ ដើមឈើ/ថ្ម ចែករំលែកគ្នា (ភ្លើងអតិបរមា ៣ តង់ ២ សម្រាប់ក្រុមទាំងមូល)។
- ឃ្លាំង និងអាវុធ ជារបស់ម្នាក់ៗ។ អ្នកណាសម្លាប់សត្វ អ្នកនោះបានសាច់។
- ស្លាប់ហើយ អាចមើលមិត្តលេងបន្ត ឬចុច “ចេញ”។ ហ្គេមចប់ពេលគ្រប់គ្នាស្លាប់ ឬម្ចាស់បន្ទប់ឈប់។
- កាក់ និងកំណត់ត្រា គិតតាមចំនួនថ្ងៃដែលខ្លួនឯងរស់បាន។

## ចំណាំបច្ចេកទេស
- ប្រើ WebRTC តាម PeerJS (ម៉ាស៊ីនមេស្វែងរកគ្នាឥតគិតថ្លៃ `0.peerjs.com` និង TURN របស់ PeerJS)។ ទិន្នន័យហ្គេមរត់ផ្ទាល់ពីម៉ាស៊ីនម្ចាស់បន្ទប់ទៅមិត្ត។
- ម្ចាស់បន្ទប់គួរប្រើអ៊ីនធឺណិតល្អ ហើយកុំបិទផ្ទាំងហ្គេម (បើបិទ មិត្តនឹងចេញពីហ្គេម)។
- ID រក្សាក្នុងគណនី។ បើបើក Cloud (README_CLOUD.md) ID និងបញ្ជីមិត្តតាមទៅឧបករណ៍ផ្សេងដែរ។
- ចង់ប្រើម៉ាស៊ីនមេ PeerJS ផ្ទាល់ខ្លួន: ដាក់ `<script>window.FN_PEER_OPTS={host:'your.server',port:443,path:'/',secure:true}</script>` មុនស្គ្រីបហ្គេម។


## v8.1: សារសំណើមិត្ត
- មានគេ Add មក → សារតូចលោតឡើងនៅ **ជ្រុងខាងស្តាំ ផ្នែកក្រោម** (ទទួល / បដិសេធ) ហើយប៊ូតុង 👥 មិត្តភក្តិ មានលេខក្រហមបង្ហាញចំនួនសំណើ។
- សារបង្ហាញតែនៅ **បន្ទប់មិត្តភក្តិ** និង **Lobby/បន្ទប់រង់ចាំ** ប៉ុណ្ណោះ។ ពេលនៅហាង វគ្គ ឬក្នុងហ្គេម សំណើនៅរក្សាទុក ហើយបង្ហាញវិញពេលត្រឡប់មក។
- សំណើក៏មានបញ្ជី «📨 សំណើមិត្តដែលចូលមក» ក្នុងបន្ទប់មិត្តភក្តិ មិនបាត់ក្នុង ១០ នាទី។
- សំណើដែលមិត្តមិនទាន់ទទួល ផ្ញើម្តងទៀតរៀងរាល់ ៨ វិនាទី (ពេលអ្នកនៅ Lobby ឬបន្ទប់មិត្តភក្តិ)។
- ចំណាំ: ដោយគ្មានម៉ាស៊ីនមេ អ្នកទាំងពីរត្រូវបើកហ្គេមនៅពេលតែមួយ ទើបសំណើទៅដល់។


## v8.8: ថ្ងៃ-យប់វែងជាងមុន + [Temple Run]
- រយៈពេល ១ ថ្ងៃ (ព្រឹក→យប់) បន្ថែម ៥០% (`DAY` ក្នុង index.html: ១៤០ → ២១០ វិនាទី)។
- **[Temple Run]** (លេងម្នាក់ឯងប៉ុណ្ណោះ): ទ្វាថ្មស្ថិតក្នុងព្រៃ។ ចុច E ក្បែរទ្វា ត្រូវមាន 🍖 សាច់អាំង ១០ + 🪨 ថ្ម ២០ + 🪵 ឈើ ២០ (រាប់កាបូប + ហិប)។
  - លួចពងក្រពើ ហើយរត់គេចឧបសគ្គ ឆ្វេង/ស្តាំ (← → ឬ A D ឬអូស) និងហក់ (Space ឬអូសឡើង) រយៈពេល ១:៥០ នាទី។
  - ឈ្នះ: ត្រឡប់មកវិញ ទទួលសារ «អ្នកឆ្លងផុត ៤ ថ្ងៃ» ហើយនាឡិកាហ្គេមរំលង ៤ ថ្ងៃ។
  - ចាញ់ (ក្រពើចាប់បាន ឬបោះបង់): ត្រឡប់មកវិញភ្លាមៗ គ្មានអ្វីទទួលបាន ហើយសម្ភារៈដែលបង់ចូលទ្វាបាត់។
  - កែតម្លៃបានក្នុង index.html: `TEMPLE_COST`, `TEMPLE_TIME`, `TEMPLE_SKIP`។
